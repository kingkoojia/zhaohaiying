德国籍客户继承苏州和香港存款：一套遗产，两套程序

涉外继承案例 更新于 2026年8月12日

被继承人在德国去世，存款同时留在中国苏州和中国香港，继承就要走两套完全独立的程序：苏州存款由内地公证处办继承权公证，香港存款由香港高等法院遗产承办处办遗产管理书。内地公证书在香港无效，这是跨境遗产继承中最容易踩的坑。

一、案件背景

陈女士（化名）是德国籍人士，生前在中国苏州和香港各留有存款。她在德国去世后，家属需要把两地的钱取出来。

卢先生被继承人的丈夫德国籍，无民事行为能力
卢小姐被继承人的女儿德国籍，作为监护人参与办理

遗产范围：苏州（中国大陆）存款、香港存款及保险。

二、案件难点

  1. 双轨程序： 内地公证书在香港无效，必须分别办理；
  2. 法律适用： 苏州部分适用"德国实体法 + 中国程序法"，香港部分适用香港法律；
  3. 文件套数： 德国文件需要准备多套，内地和香港的翻译、公证要求不同；
  4. 监护人身份： 继承人无民事行为能力，监护文件也要认证；
  5. 香港担保： 非香港居民办理遗产承办通常需要担保或保证人。

三、办案经过

第一步：德国文件预处理

  1. 取得德国法院继承文书（继承权证书 Erbschein）、死亡证明、亲属关系证明；
  2. 办理德国海牙认证（Apostille）；
  3. 准备英文、简体中文、繁体中文翻译件。

第二步：苏州（内地）继承公证

  1. 由有涉外资质机构翻译德国文件；
  2. 公证处办理"译文与原文一致"公证；
  3. 向南京公证处申请继承权公证（本案苏州公证处不办此类业务）；
  4. 公证处审核后出具继承权公证书，凭公证书到银行支取苏州存款。

第三步：香港遗产承办

  1. 德国文件交香港认可机构译成英文/繁体中文；
  2. 香港国际公证人公证；
  3. 填写香港高等法院 N4.1 遗产清单表格、准备继承人誓章；
  4. 德国律师出具继承法律意见书（宣誓证明书）+ 海牙认证 + 香港翻译公证；
  5. 落实担保金或香港居民保证人；
  6. 法院审核后签发遗产管理书，凭此到香港银行支取。

四、法律要点

1. 内地与香港程序独立

现象： 同一笔遗产分布在两个法域。

风险： 用内地公证书去香港办，不会被认可；反之亦然。

建议： 两套材料、两套程序、两个时间表，分别推进。

2. 翻译与公证的地域差异

现象： 德国文件需要翻译。

风险： 内地翻译公证香港不认可。

建议： 内地做中文翻译 + 翻译公证；香港做英文/繁体中文翻译 + 香港国际公证人公证。

3. 监护人身份

现象： 继承人无民事行为能力。

风险： 监护文件不认证，无法代签、无法办理。

建议： 法院监护令、养老监护授权书一并公证 + 海牙认证 + 翻译。

五、给客户的建议

  1. 德国文件准备 3-5 套原件 + 海牙认证，内地、香港各用一套；
  2. 优先办内地程序，同步筹备香港材料，节省总时间；
  3. 非香港居民提前准备担保或保证人；
  4. 小额遗产可走简易通道： 存款 ≤5 万港币走民政事务总署确认通知书，≤15 万港币走遗产管理官简易程序。

常见问题解答（FAQ）

Q1：内地继承权公证书能在香港用吗？

A：不能。香港遗产承办是独立程序，内地公证书在香港无效，必须单独向香港高等法院遗产承办处申请。

Q2：德国文件在中国怎么认证？

A：德国法院/公证机构出具的文件，经海牙认证（Apostille）后，内地做中文翻译公证，香港做英文/繁体中文翻译 + 国际公证人公证。

Q3：非香港居民办理遗产承办难吗？

A：程序本身规范，但通常需要遗产全额担保或 2 名香港居民保证人，建议提前准备。

Q4：两地办理要多久？

A：苏州约 10-12 个月，香港约 12-14 个月，可并行推进。
