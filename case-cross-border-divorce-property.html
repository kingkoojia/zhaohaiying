跨国离婚，对方隐藏财产怎么办？调查令与跨境证据实务

跨国离婚案例 更新于 2026年8月12日

涉外离婚案件的真正难点往往不是"离不离"，而是财产查不查得全、查得到的财产能不能分得到。对方隐瞒账户、转移股权、漏报保险，都可以通过法院调查令逐项查明；婚姻过错方依法应少分财产。本文以一对中德跨国夫妻离婚案为线索（人物均为化名），讲清财产调查和跨境证据的实务要点。

一、案件背景

陈先生（中国籍）与唐女士（德国籍）结婚多年，育有一女。两人长期分居两国，婚姻破裂后，陈先生提起离婚诉讼。

人物身份关键信息
陈先生原告中国籍，名下有多处房产、公司股权和银行账户
唐女士被告德国籍，长期带女儿在德国生活
女儿婚生女德国籍，随母在德国生活
承办律师赵海英代理被告唐女士

争议焦点：离婚、女儿抚养权与抚养费、夫妻共同财产分割、婚内过错与补偿。

二、案件难点

  1. 财产分散： 房产、公司股权、多类银行账户、理财、保险、公积金、养老金分散在多个机构；
  2. 申报不实： 对方财产申报不完整，多个账户、保单、理财未申报；
  3. 股权转移： 婚姻期间股权被转移至关联公司；
  4. 跨境证据： 境外护照、出生证、聊天记录等需公证认证和翻译；
  5. 抚养费标准： 女儿在德国生活，抚养费应按德国生活水平主张。

三、办案经过

第一步：身份与境外证据准备

  1. 办理女儿出生证、护照、唐女士身份证明的公证认证与翻译；
  2. 委托书在德国公证并配套翻译件；
  3. 境外聊天记录、短信通过德国公证机构公证并附翻译件。

第二步：财产申报与法院调查

  1. 法院发出夫妻共同财产申报告知书、申报表、承诺书；
  2. 提交代理意见、答辩意见和对财产申报的质证意见；
  3. 申请多份法院调查令：交通银行、网商银行、上海银行、农业银行、盛京银行、财付通（微信）、支付宝、税务局、公积金中心、车管所、证券结算机构、保险公司等；
  4. 申请对公司股权和房产进行评估。

第三步：调解与庭审

  1. 提交财产分割方案，明确不同比例下的分割款测算；
  2. 形成离婚调解协议草案：各自名下财产归各自所有，对方一次性支付财产分割款及抚养费；
  3. 同步主张过错方少分财产、补足抚养费及各项补偿。

四、法律要点

1. 调查令是查清财产的钥匙

现象： 一方隐瞒银行存款、理财、保险、微信/支付宝资金。

风险： 不掌握完整财产线索，离婚后难以再主张分割。

建议： 申请法院签发多份调查令，覆盖银行、支付工具、证券、保险、税务、公积金、车辆、房产；发现转移股权的，申请法院调查关联公司。

2. 隐藏、转移财产的一方应少分

现象： 婚姻期间将股权转至关联公司、漏报账户。

风险： 若无证据，财产按一般规则分割。

建议： 依《民法典》第一千零九十二条，主张对隐藏、转移、挥霍共同财产的一方少分或不分。

3. 跨境证据的公证认证

现象： 境外护照、出生证、聊天记录需提交中国法院。

风险： 未经公证认证、翻译的证据不被采纳。

建议： 按"公证 + 认证 + 国内法院认可翻译公司翻译"流程准备；聊天记录通过境外公证机构公证并附翻译件。

五、给客户的建议

  1. 财产线索越早固定越好： 账户、卡号、保单号、转账记录都要留存；
  2. 调查令覆盖面要全： 银行、支付宝/微信、证券、保险、公积金、养老金一样不能少；
  3. 境外证据提前启动认证： 避免耽误开庭；
  4. 调解与诉讼双线准备： 掌握"最低可分财产 + 抚养费 + 补偿"的完整测算。

常见问题解答（FAQ）

Q1：对方不提供银行流水，怎么查？

A：可以向法院申请调查令，由律师持令到银行、支付机构、证券公司等调取，无需对方配合。

Q2：对方把股权转到别的公司，还能分吗？

A：可以。通过调查令查明关联公司股权结构，主张婚姻期间取得的股权属于夫妻共同财产，转移行为不能对抗合法分割。

Q3：境外的聊天记录能作为证据吗？

A：可以，但需经境外公证机构公证并附中文翻译，认证链完整才会被法院采纳。

Q4：孩子随外籍一方在国外生活，抚养费怎么定？

A：法院会结合孩子实际生活地的消费水平、父母收入和实际需要确定，可提供当地生活成本数据作为参考。
