美国籍母亲在中国留下的存款，两个女儿如何继承？

涉外继承案例 更新于 2026年8月12日

父母在海外去世，国内的存款不会"自动消失"，但继承要走一套严格的程序：境外文件先做公证和海牙认证，再翻译公证，最后办继承权公证，凭公证书到银行支取。本文以一位美国籍母亲去世后、两位美国籍女儿继承其国内存款的真实案例为线索（人物均为化名），讲清涉外继承的全流程。

一、案件背景

唐女士（化名）早年入籍美国，晚年定居美国。2024 年初在美国去世后，她在中国境内留有银行存款等遗产。两位女儿均已入美国籍、长期生活在美国，无法回国办理手续。

遗产范围：中国境内银行存款等动产（以银行查询告知书为准）。

二、案件难点

  1. 法律适用： 被继承人为美国籍，动产继承应适用哪国法律，需要先确定；
  2. 境外文件： 死亡证明、同一人证明、继承权宣誓书等均为外文，需公证 + 海牙认证 + 翻译公证；
  3. 姓名衔接： 中英文姓名、新旧证件写法不一致，需要同一人证明打通；
  4. 程序衔接： 继承权公证、银行查询、支取、资金出境环环相扣；
  5. 家庭沿革： 配偶先逝时的继承、放弃继承文件，影响继承人范围认定。

三、办案经过

第一步：境外文件准备

  1. 取得被继承人美国死亡证明，并经州务卿出具 Apostille；
  2. 办理被继承人、继承人同一人证明（Affidavit of One and the Same），经加州公证 + Apostille；
  3. 准备继承人美国护照及身份文件。

第二步：委托与合同

  1. 签署律师服务合同，委托办理中国境内继承；
  2. 签署《委托书》，授权办理公证申请、材料提交、遗产查询、继承手续、缴费、领证等；
  3. 签署《查询函》，授权查询被继承人名下银行账户余额。

第三步：继承权公证

  1. 向公证处申请继承权公证；
  2. 提交身份证明、死亡证明、亲属关系证明、财产凭证、经认证的继承权宣誓书和亚利桑那州法律；
  3. 公证处核查遗嘱信息后出具继承权公证书，确认两女儿共同继承。

第四步：银行支取与资金出境

  1. 凭公证书及身份文件向银行办理遗产查询、支取；
  2. 现金部分按外汇管理规定从继承人中国境内账户转至境外账户。

四、法律要点

1. 涉外继承的法律适用

现象： 被继承人外国籍，遗产在中国。

风险： 法律适用判断错误，公证处不予受理或继承人资格认定错误。

建议： 依《涉外民事关系法律适用法》第三十一条，法定继承适用被继承人死亡时经常居所地法律（动产）；本案适用美国亚利桑那州法律，需提交经认证的法律意见书。

2. 境外文件的认证链

现象： 外文死亡证明、亲属关系文件需在国内使用。

风险： 未经公证认证的文件不被公证处认可。

建议： 全部按"当地公证 + 海牙认证 + 国内翻译 + 译本相符公证"准备；涉及姓名/证件变更的，另出同一人证明。

3. 银行遗产查询与支取

现象： 继承人不知道具体账户和金额。

风险： 材料不全无法支取；遗产范围不锁定，公证内容不完整。

建议： 先通过银行查询函锁定遗产范围，再办继承公证；凭公证书正本到银行支取。

五、给客户的建议

  1. 境外文件按"三件套"准备： 公证 + 海牙认证 + 翻译公证，缺一不可；
  2. 同一人证明很关键： 中英文姓名、新旧证件都要打通；
  3. 先查后办： 先让银行/公证处查存款，再办公证，遗产范围更清楚；
  4. 家庭沿革一并归档： 配偶先逝、放弃继承、转继承文件都要留好。

常见问题解答（FAQ）

Q1：外籍子女能继承父母在中国的存款吗？

A：可以。继承权不因国籍受影响，外籍继承人与中国籍继承人权利平等。

Q2：美国出具的文件在中国怎么用？

A：需经美国公证 + 州务卿 Apostille（海牙认证），再由国内有资质机构翻译、办理"译本与原本相符"公证。

Q3：人不在国内怎么办公证？

A：通过经公证认证的委托书，可远程委托中国律师办理继承公证、银行查询和支取手续。

Q4：继承的钱怎么汇到国外？

A：需办理税务备案和外汇审批，凭继承公证书、完税凭证等材料申请购付汇。
